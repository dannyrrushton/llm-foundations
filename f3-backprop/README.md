# F3 · Backpropagation by hand

Not started yet.

When it starts, set it up like every project here, in its own virtual environment:

```bash
./setup_venv.sh f3-backprop
source f3-backprop/.venv/bin/activate
```

**The exercise:** Build a tiny automatic-differentiation engine that tracks scalar values and their gradients (in the spirit of Karpathy's micrograd), and train a small network with it. Check every gradient against finite differences and against PyTorch's autograd.

Written up at [danielrushton.com/writing/f3-backprop-by-hand](https://danielrushton.com/writing/f3-backprop-by-hand/) once published.
