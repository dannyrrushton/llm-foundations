# F3 · Gradient descent by hand

Not started yet.

When it starts, set it up like every project here, in its own virtual environment:

```bash
./setup_venv.sh f3-gradient-descent
source f3-gradient-descent/.venv/bin/activate
```

**The exercise:** In NumPy, fit a straight line with gradient descent, then a small two-layer network. Sweep the learning rate and watch training crawl, converge, then diverge. Check the fitted line against the exact least-squares solution.

Written up at [danielrushton.com/writing/f3-gradient-descent-by-hand](https://danielrushton.com/writing/f3-gradient-descent-by-hand/) once published.
