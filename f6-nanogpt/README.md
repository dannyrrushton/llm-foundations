# F6 · Training a tiny GPT on one GPU

Not started yet.

When it starts, set it up like every project here, in its own virtual environment:

```bash
./setup_venv.sh f6-nanogpt
source f6-nanogpt/.venv/bin/activate
```

**The exercise:** Train the small Shakespeare GPT on a single GPU, built from F4's attention. Print one attention head's weights for one sentence, and profile which operation dominates a training step.

Written up at [danielrushton.com/writing/f6-tiny-gpt-one-gpu](https://danielrushton.com/writing/f6-tiny-gpt-one-gpu/) once published.
